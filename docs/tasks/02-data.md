## 修改范围

允许 backend/app/models、db、schemas、services 中编号/可见性基础、backend/alembic、backend/tests 和相关文档。业务 API、前端和真实数据只读；必要共享配置修正须记录。

## 执行步骤

1. 依据 ER 图实现所有实体、关联表、通用时间戳、version、deleted_at、枚举、外键、唯一约束和科研 Numeric 类型。
2. 生成并检查初始 Alembic 迁移；禁止 create_all 代替迁移。数据库级检查覆盖数值/单位成对、角色和收率限制。
3. 编号使用 NumberCounter 事务内原子取号并加唯一约束；创建年份用 APP_TIMEZONE，CMP year=0。允许跳号，禁止 max/count + 1。
4. 建立可复用有效记录过滤及版本更新基础；明确父级隐藏不改写子级自身删除状态。
5. 使用真实 PostgreSQL 和独立连接编写约束、事务与并发测试；提供可控时钟，不靠真实等待跨年。
6. 记录实际 schema 与设计差异；发现设计必要变更时写决策，不能擅自删除原文要求的实体。
