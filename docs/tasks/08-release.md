# 阶段 08 集成验收与交接

你是本阶段执行者。本任务依赖当前工程文件，不依赖此前聊天。先读 PLAN.md、PROGRESS.md、BLOCKED.md，核对实际实现后接续；不要从头重写已完成模块。目标优先级：数据安全与正确性 > 功能闭环 > 易维护 > 速度。

## 前提和约定

- 前置：07 通过。
- 必读：PLAN.md 与所有详细规格，尤其 docs/acceptance.md 的全部行；PROGRESS.md 与 BLOCKED.md。
- 默认决策：仅本机个人使用，中文界面，Asia/Shanghai；按详细规格实现，不自行加入 AI、多用户或自动科学计算。

## 修改范围

允许 tests/、scripts/check.sh、README.md、设计/进度文档及验收发现的最小必要业务修复。禁止趁收尾引入新功能、替换技术栈、删测试或清空用户数据。

## 执行步骤

1. 建立/完善 Playwright 和 e2e/all 检查入口；浏览器使用真实 backend、PostgreSQL 与测试文件存储，不能截获全部请求返回假数据。
2. 完成化合物→实验→样品/反应→上传→搜索→摘要→删除→恢复的端到端流程，校验实际记录和下载字节。
3. 检查浅/深色、两种桌面尺寸、长中文标题/SMILES、键盘焦点、空页面、网络失败、冲突提示；修复实际问题并重跑受影响检查。
4. 使用新的隔离项目和空数据按 README 逐项启动，不依赖本地旧容器或已有 schema；测试停止和重启后持久化。
5. 运行完整后端、前端、e2e 检查，逐条给 acceptance ID 对应证据，未跑项目不能标通过。
6. 校准 README 与 docs 的实际版本、配置、启动/检查/备份/恢复步骤。PROGRESS.md 写交付状态，BLOCKED.md 无剩余问题时明确“当前无未解决阻塞”。
