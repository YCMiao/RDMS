# 界面与交互规格

## 通用布局

中文界面，英文实体术语可在标题辅助说明。桌面优先，在 1280×800 与 1440×900 验收；较窄屏幕允许表格横向滚动，不隐藏关键操作。左侧固定导航 Dashboard、Experiments、Compounds、Samples、Files、Search、Settings；顶部全局搜索提交后进入搜索页。业务编号、时间、状态等在表格中保持易读，正文与长字符串允许换行。

主题默认跟随系统，可手工选择浅色/深色并存到 localStorage。采用 shadcn/ui 标准控件、低饱和中性色、清楚的边界与焦点，首页使用 Canvas 粒子圆盘，遵循系统减少动态效果与后台暂停，离开页面清理动画。键盘可访问按钮、表单和对话框；错误不能只用颜色表达。科研数值使用文本/十进制输入，不强制转成 JS Number。

## 页面

| 路由 | 内容和操作 |
|---|---|
| / | 粒子圆盘和业务导航；统计与最近记录仍由 dashboard API 提供 |
| /experiments | 默认显示记录本卡片（创建、改名、归档）；指定 notebook 或 view=all 时显示实验列表：编号、标题、日期、状态；记录本范围、搜索、日期筛选、编号/标题/日期双向排序、分页、复制及多选移本 |
| /experiments/new | 创建实验表单；编号创建成功后显示 |
| /experiments/:id | 基本信息与编辑；目的与默认折叠的统一备注，旧分类正文兼容显示；相关化合物、样品、反应列表、附件、摘要 |
| /compounds | CAS、系统名称、分子式、分子量、代号、标签；CAS/名称/代号/SMILES 搜索、分页、多选批量标签 |
| /compounds/:id | 详情和编辑，分别分页显示实验、反应、样品 |
| /samples | 编号、名称、实验、化合物、类型、数量；筛选、创建与编辑 |
| /samples/:id | 样品信息、来源链接、相关附件 |
| /files | 原名、所属实验、样品、类型、大小、上传时间；筛选、详情页、下载、上传、删除 |
| /search | 实验/化合物分组结果、命中字段、各自分页 |
| /settings | 只读时区与上传限制说明、标签管理、回收站、手动备份说明；全局外观控件位于侧栏底部，窄屏位于搜索栏旁 |

化合物支持 CAS 弹窗及独立新建/结构导入页，样品在列表内创建；实验主体使用页面表单。反应在实验详情内创建和编辑，组分采用可逐行保存的表格；添加时必须通过已有 Compound 选择器，提供创建化合物后回填，不接受游离名称冒充关联。

## 表单和关联

- 必填字段明确标示；服务端字段错误映射到控件，保留用户输入。
- 保存中禁用重复提交；失败显示原因与重试。编辑后离开页面提示未保存。
- 409 版本冲突提示刷新，允许复制尚未保存的文本；不能自动用本地内容覆盖新版本。
- 显式关联和推导关联分别标注来源；“解除关联”仅作用于 explicit 来源，即使解除后仍可能通过反应或样品出现。
- 关联选择器分页搜索；已删除记录不能选用。
- 单独文件上传显示选定实验、可选样品、大小限制、每个文件的独立状态和进度。支持连续选择多个文件，但每次请求只传一个。
- 删除实验对话框说明子记录会隐藏、原始文件保留且可恢复；删除标签说明会清除分类关联且不可通过科研回收站恢复。
- 回收站按实体类型分页；恢复受父级或化合物阻塞时显示具体原因和导航入口。

## 摘要

实验详情点击“生成摘要”后实时读取已保存数据，展示生成时间和内容版本，支持复制及下载 Markdown。模板顺序：实验编号/标题/日期/状态 → 目的 → 统一备注（兼容旧分类正文）→ 反应与组分 → 样品 → 文件。空值显示“未记录”。摘要不保存为独立数据库记录，不分析谱图、不补写产率、不暗示已验证科学结论。

## 状态验收

每个页面覆盖加载、空数据、无搜索结果、请求失败和成功五种状态；无数据时提供合理创建入口。失效或已删除的深链接显示 404 提示和返回列表入口。检查长标题、长 SMILES、中文文件名、暗色表格、键盘焦点、对话框高度以及网络错误。不得仅用静态假数据截图判定功能完成。
