# 实验记录本

实验入口按卡片展示记录本。点击卡片进入本内实验列表；“全部实验”可跨本查找。记录本包含名称、固定代号、可选说明、有效实验数量与最近记录日期。可创建、编辑、归档和取消归档；归档不隐藏有效实验，但停止向该本新建、复制、移入或恢复实验。

每个实验仅属于一本。记录本代号自动分配为 NB001、NB002 等，不随改名变化；本内实验编号为 NB001-0001 等，跨年连续。服务器锁定记录本计数器，在同一事务内分配编号与保存实验。同一本内序号及完整实验编号均有唯一约束；删除、移出和恢复不会复用已提交过的编号，四位以上序号不截断。

新建默认选择当前本，跨本列表或直接打开新建页时默认选择“已有实验”，可修改。复制可选择目标本，原有反应、投料及产物复制规则保留。实验详情及列表多选可移入其他本：先预览目标编号，确认后整批更新。原本内相对顺序保留；已在目标本的实验不重新编号。预览后目标计数器或实验版本变化会拒绝执行，需要重新选择目标本预览。失败时整批回滚，不部分移入。

回收站恢复实验前须选择未归档的目标本，恢复分配新编号，继续检查原有化合物依赖；恢复不会自动恢复单独删除的子记录。删除记录不会物理删除数据库行或原始上传文件。
